# N-CMAPSS 校准截点扩展臂（Arm B）预注册

日期：2026-11-05（运行前登记）

## 动机（诊断事实）

P0 外部检查中，DS03/DS08a 的三个 CQR 变体阈值逐位相同
（16.6273 / 16.3764）：2 个校准引擎 × 4 截点 = 8 个校准窗，
α=0.2 的有限样本分位数 = ceil(0.8×9)−1 = 第 8 个 = 最大分数，
加权分位数被保守原子推至不小于该值——密度比加权机制自由度为零。
PICP .917、MPIW 61–69 的过覆盖由此而来。

## 设计（冻结项与唯一变量）

- **冻结**：registered split（4/3/2，split_seed=0，引擎集合不变）、
  A6-Quantile checkpoint（P0 已冻结产物，只读）、测试端点、α=0.2、
  密度比配置（特征/clip=20/C=1/StandardScaler/balanced）、normalization=1.0。
- **唯一变量**：校准截点网格，从现行 4 截点 {0.25,0.5,0.75,0.9} 扩展为
  预注册网格：
  - **G9**：{0.10,0.20,…,0.90}（9 截点 → 18 窗）
  - **G17**：{0.10,0.15,…,0.90}（17 截点 → 34 窗）
  - 截点位置 = round(frac×(n−1))，n 为引擎序列长度
    （与 fixed-cuts 协议同一公式，取自 bundle 元数据）。
  - 两个网格同时报告，不做网格间选择。
- 窗口构造：从 bundle.calibration 全窗口集中按 (unit, 末端周期索引)
  选取；与端点采样同一 `_pad_window` 与标签语义（NC 无 cap，原始标签）。

## 判读与边界

- 本臂为**机制诊断**：验证"校准样本扩容能否恢复加权机制的分辨率、
  收窄区间"，不改变 FD 生产配置，也不据此宣称 NC 覆盖保证。
- 所有网格 × 变体与 Arm A（现行 4 截点）并排报告；不按 test 数字挑
  胜者；测试端点按一次性评估并记入 test_touches.log。
- 预期（登记时判断，供事后对照）：n_cal 从 8 → 18/34 后，80% 分位数
  不再等于最大分数；若加权与 global/block-max 阈值开始分化且 PICP
  向 [0.75,0.85] 回落、MPIW 收窄，支持"样本量是 NC 主瓶颈"的归因。
