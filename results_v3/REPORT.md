## 链式归因读法(单 seed,噪声带中位 ~0.9 RMSE)

1. **单读出(A1−A0):无害,阶段一门通过。** FD002 小幅全面改善(val_fc −0.74、RMSE −0.61、MAE −0.87),FD004 打平(RMSE +0.20、val −0.24,均在噪声内;NASA +25% 由单点驱动)。单读出信息瓶颈不存在,后续链以此为基础成立。
2. **端点对齐均值池化(A2−A1):无收益,方向略负**(val_fc +1.0/+1.3)。边界修正本身不成立。
3. **可学习降采样(A3−A2):链内第一个确定的正贡献**,FD004 RMSE −1.89 超出噪声。
4. **矩约束 vs 无约束(A4 vs A3):打平,不支持"保趋势压缩"精度主张**(差距 ≤0.33 val_fc,方向不一)。按 §10 预注册门,该主张不写;其价值需机制诊断或多 seed。
5. **趋势读出(A5−A4):链内最大增益**,两数据集 test RMSE −1.61/−1.82、MAE −0.91/−2.01、NASA −37%/−19%、corr 0.889→0.909,val 方向一致。**当前最有希望成为真实贡献的机制。**
6. **动态图(A6/A7−A5):小幅、方向不一致**;A6(幅值图)综合略优于 A7(趋势图)。**"趋势可靠度驱动图更有效"这一核心机制主张在单 seed 下不成立**(A7≈A5,A7< A6 于 FD002)。§10 干预检查(趋势打乱、λ=0)未做,不能断言动态图实际使用了趋势信息。
7. A5+ 各臂 corr 0.908–0.912,超过 FCSTGNN(0.901/0.903);test MAE/RMSE 对 FCSTGNN 优势 −1.3~−2.3/−2.4~−3.8,量级超出噪声带。但叠加三个警示:单 seed、A 系列配置设计时接触过历史 test(文档已声明)、fixed_cuts 协议本身对旧结果的不可比性。另注:A0(25.12/26.82 RMSE)与旧 B3+pcnn(25.62/28.70,旧协议+旧种子时机)不可直接配对,差异含协议与种子时机两个混杂因素。

## N-CMAPSS:A6 vs FCSTGNN 外部复核(seed=0)

**数据事实(本轮发现):** 公开版 DS03/DS08a 的 test 轨迹是**完整寿命**(每 unit 末端 Y=0,425 万/372 万行),"末端窗口"评估退化为对 0 预测(首轮运行因此作废)。修正后的冻结评估:与验证同款 fixed cuts {0.25,0.5,0.75,0.9} 截断每个 test unit,取中寿命端点窗口(6 units × 4 = 24 窗口),标签取文件中该点 Y(6–69 flights)。协议其余部分:unit-cycle 均值聚合(X_s 14 通道,T 排除)、全局 z-score(train units 拟合)、7/2 dev 划分、无 cap、Adam batch 32 × 300 epochs(N-CMAPSS 注册预算,FD 的 41 epochs 不适用)。

### A6 调参网格(`ncmapss_tune/`,8 配置 × 2 数据集,seed=0,按 val_fc 选择)

轴:容量(d64/d32/d16 × routers/heads 同步缩放)、wd 1e-3、dropout 0.2、工况 full/mean/none、lr 3e-4+600ep。完整表 `ncmapss_tune_summary.csv`。

| DS | val_fc 选中的配置 | 该配置 test MAE/RMSE | test 最优配置(事后) | test 最优 MAE/RMSE |
|---|---|---|---|---|
| DS03 | t5(d32+mean) | 9.95 / 14.03 | t3(d32+wd) | 9.27 / 13.17 |
| DS08a | t0(default d64) | 14.22 / 18.07 | t4/t1(d32±do) | 10.36–10.95 / 13.09 |

结论:
1. **容量是最大杠杆**:138k 在 7-unit 数据上过拟合(DS08a 尤甚,worst-unit MAE 27.9→13);d32 家族(36k)把 DS08a test RMSE 18.07→13.09–13.39。d16(9.9k)欠容量。t7(lr 3e-4+600ep)两数据集均差(RMSE 18.0/14.80)。
2. **工况输入必需**(t6 无工况:DS03 RMSE 22.41);full 与 mean 方向不一。
3. **跨数据集最稳的单配置是 t3(d32+wd 1e-3)**:DS03 9.27/13.17、DS08a 10.94/13.39——DS08a 上优于 FCSTGNN(11.50/14.97),DS03 仍逊于 FCSTGNN(8.20/11.06)。
4. **网格暴露的选择可靠性问题比超参本身更重要**:val_fc(2 个独立 unit、8 个窗口)的排序与 test 排序明显脱节——严格按 val_fc 会在 DS08a 选中过拟合最重的 t0。任何"调参后最佳配置"的声称都受此限制;可靠的选择需要 dev 单位级交叉验证或更多 seed,而不是更大网格。

**读法(外部复核性质,不作确认性主张):**
- **FCSTGNN 在两数据集的中寿命端点 test 指标上均优于 A6**(DS03 RMSE −3.5,DS08a −3.1),且参数量为 1/6。A6 的 FD 优势未迁移到 N-CMAPSS。
- val_fc 与 test 方向相反(A6 双数据集 val 更好):仅 2 个独立 val unit 的选择信号不可靠(§14.1 已预警),checkpoint 选择本身是本轮最大的噪声源。
- 逐 unit:FCSTGNN 误差分布更均匀;A6 在个别 unit 上失稳(DS08a 单 unit MAE 27.9)。
- FCSTGNN 维度为 history 16 适配(time_len 8 × patch 2),未调参;A6 为 FD 配方直接迁移。两者都不能声称达到各自最优配置。
- 按 refine-logs 计划 B3 的限制条款:6 个 test units 不能支撑强总体主张,本轮定位为**可行性/外部复核**,结论是"FD 结论外推到 N-CMAPSS 需重新验证",而非"A6 差于 FCSTGNN"。
